# Hermes

T3 Code can drive your existing Hermes Agent installation. Hermes keeps its own profile, models,
credentials, memory, skills, and session history; T3 Code starts and continues Hermes conversations
through the same gateway the Hermes terminal UI uses.

## Set Up Hermes

1. Install Hermes Agent on the machine running the T3 Code server and finish `hermes setup`.
2. Open T3 Code Settings, enable Hermes, and refresh the provider.

T3 Code looks for Hermes in `~/.hermes`. Set **Hermes home** if it lives elsewhere, and **Profile**
to use a named Hermes profile. Add another Hermes provider instance for each profile you want to
use. **Python path** is only needed for unusual installs.

## Conversations

The model picker lists the models from your configured Hermes providers. **Hermes default** keeps
the model the profile (or that conversation) already uses. Model, reasoning, and fast-mode picks
apply to the T3 Code conversation only; they never change your Hermes configuration.

Hermes conversations from other surfaces (CLI, desktop, Slack, cron) can be continued in T3 Code.
While a turn runs, Hermes reserves the conversation for T3 Code. T3 Code releases it about 30
seconds after the reply finishes, so you can pick the same conversation up in Slack or the CLI. If
another Hermes client is using the conversation when you send, T3 Code shows that it is active
elsewhere; send again once it is idle.

Forking a Hermes thread creates a new Hermes conversation with the full text history. Hermes can
fork only a whole conversation, and it cannot rewind one, so reverting to an earlier turn is not
available for Hermes threads.

Hermes questions and command approvals appear in the composer. Delegated subagents and todo lists
show their progress in the thread.

## Permission Modes

- **Supervised** follows your Hermes `approvals.mode`. If Hermes asks for approval, T3 Code shows
  the prompt with Hermes' own choices.
- **Full access** turns on Hermes' per-conversation auto-approve for the T3 Code session.

## Troubleshooting

- If Hermes is unavailable, run `hermes doctor` in a terminal on the server machine, then refresh
  the provider.
- If no models appear, run `hermes model` or `hermes setup` and refresh the provider.
- Thread titles and commit messages are generated by another provider; Hermes is not used for
  background text generation.
